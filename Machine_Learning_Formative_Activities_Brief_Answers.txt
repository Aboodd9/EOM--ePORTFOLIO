UNIT 3 — CORRELATION AND REGRESSION
Answer: Pearson correlation measures linear association from -1 to +1. Simple linear regression estimates y_hat = b0 + b1*x. Correlation does not imply causation, and outliers may change both results.
Illustrative calculation: x = [1,2,3], y = [2,4,6]. The correlation is 1, slope b1 = 2 and intercept b0 = 0. For x = 4, predicted y = 8. Perfect fit in this tiny example does not establish real-world predictive reliability. Examine residuals and evaluate unseen observations.

UNIT 5 — JACCARD COEFFICIENT CALCULATIONS
Answer: J(A,B) = |A intersection B| / |A union B|.
Illustrative example: A = {a,b,c}, B = {b,c,d}. Intersection size = 2; union size = 4; J = 0.50. Jaccard distance = 1 - J = 0.50. For two empty sets, state the convention used by the chosen software. Joint absence is excluded in ordinary binary Jaccard similarity.

UNIT 7 — PERCEPTRON ACTIVITIES
Answer: A binary perceptron predicts 1 when w*x + b >= 0, otherwise 0. Update w_new = w + learning_rate*(y-y_hat)*x and b_new = b + learning_rate*(y-y_hat).
Illustrative example: x = (1,1), y = 0, initial w = (0,0), b = 0 and learning rate = 0.1. The stated threshold predicts 1, so updated w = (-0.1,-0.1) and b = -0.1. A single perceptron cannot solve XOR with the original inputs because XOR is not linearly separable. The schedule places this activity in Unit 7 with completion by Unit 10.

UNIT 8 — GRADIENT COST FUNCTION
Answer: For linear regression, J(w,b) = (1/(2m))*sum((w*x_i+b-y_i)^2). The gradients are dJ/dw = (1/m)*sum((y_hat_i-y_i)*x_i) and dJ/db = (1/m)*sum(y_hat_i-y_i). Update each parameter by subtracting learning_rate times its gradient.
Illustrative example: One observation x = 2, y = 4; start w = 1, b = 0. Prediction = 2, J = 2, dJ/dw = -4 and dJ/db = -2. With learning rate 0.1, update simultaneously to w = 1.4 and b = 0.2. New prediction = 3 and new J = 0.5.

Answer: A typical image-classification CNN applies convolution and ReLU, optionally pooling, followed by a classification head. Convolutions learn local patterns with shared weights. For illustration, a 28x28 input with a 3x3 kernel, stride 1 and no padding produces 26x26 spatial output; eight filters produce 26x26x8. UNIT 11 — MODEL PERFORMANCE MEASUREMENT
Answer: Choose metrics for the task. Classification: precision = TP/(TP+FP), recall = TP/(TP+FN), F1 = 2PR/(P+R). Illustratively, TP = 8, FP = 2, FN = 2 and TN = 8 give accuracy, precision, recall and F1 of 0.80.
Regression: RMSE = sqrt(mean((y_hat-y)^2)). Illustratively, true ratings [4,2] and predictions [3,3] give RMSE = 1.
Ranking: NDCG@10 rewards relevant films near the top. With one relevant item ranked second, binary gain and no other relevant items, NDCG@10 = 1/log2(3), approximately 0.631. State relevance rules and candidate selection. Use untouched test data and report variation where possible. These are worked examples, not results from the attached presentation.
